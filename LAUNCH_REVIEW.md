# Product and launch boundaries

Grok Team Forge is a deterministic workflow builder and manual Grok Chat companion. Its original value is editable contracts, repeatable synthetic stress tests, a bounded real-output import/check path and portable evidence export.

One supervised real Scout response passed 47 bounded checks on fictional test data; Verifier was prepared, not run. See [the recorded summary](docs/EXPERIMENT_SUMMARY.md).

Use the launch direction “define the handoff, test the artifact, keep the evidence.” Avoid native Bot, self-improvement, autonomous-team, universal security or accuracy claims. Never relabel synthetic controls as genuine model failures.

Repository and site are now public: https://github.com/Velkrux/grok-team-forge and https://velkrux.github.io/grok-team-forge/ . Actual CI/deployment succeeded; [the report](TEST_REPORT.md) distinguishes verified flows from the unverified hosted ZIP download.
